# کاسپین — رزومهٔ تعاملی

صفحهٔ رزومهٔ **سید امیرمحمد گلستانه (سپهر) — کاسپین**، به‌صورت یک فایل HTML مستقل (`index.html`).
بدون بیلد، بدون فریم‌ورک و بدون وابستگی به سرور؛ کافی است فایل را باز کنید یا روی GitHub Pages بگذارید.

## چه چیزهایی دارد؟

- **دوزبانه (فارسی / انگلیسی)** با چیدمان RTL و LTR، ذخیرهٔ انتخاب زبان در مرورگر و به‌روزرسانی خودکار `title`، `description` و `dir`.
- **تم تیره و روشن** با تشخیص تم قبلی، احترام به تنظیمات سیستم و به‌روزرسانی `theme-color` مرورگر موبایل.
- **پالت دستورها (Command palette)** با `Ctrl/⌘ + K`: پیمایش بخش‌ها، تغییر زبان و تم، کپی آیدی‌ها، ذخیرهٔ مخاطب و گرفتن PDF.
- **خروجی PDF تمیز**: دکمهٔ «رزومه (PDF)» یا `Ctrl/⌘ + P` یک نسخهٔ دو صفحه‌ای A4 با سربرگ، بدون افکت‌ها و در جهت درست متن تولید می‌کند.
- **ذخیرهٔ مخاطب (vCard)**: فایل `.vcf` با نام، لقب، شهر و راه‌های ارتباطی می‌سازد.
- **کپی سریع آیدی‌ها** در تلگرام و بله با پیام تأیید.
- **دسترس‌پذیری**: ناوبری با کیبورد، `skip link`، `aria-*` روی کنترل‌ها، احترام به `prefers-reduced-motion` و نسخهٔ خوانا بدون جاوااسکریپت.
- **موبایل**: نوار پایین (dock) شیشه‌ای، چیدمان یک‌ستونی و بهینه‌سازی اندازه‌ها تا ۳۲۰ پیکسل.
- **سئو**: داده‌های ساختاریافتهٔ `schema.org/Person`، تگ‌های Open Graph و فاوآیکون SVG درون‌خطی.

## اجرا

```bash
# فقط باز کردن فایل
open index.html          # macOS
xdg-open index.html      # Linux

# یا سرو کردن محلی
python3 -m http.server 8080
```

## انتشار روی GitHub Pages

تنظیمات مخزن → **Pages** → شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید. صفحه روی
`https://<username>.github.io/Rezome/` بالا می‌آید.

## ساختار

همه‌چیز در یک فایل است: توکن‌های طراحی با CSS Custom Properties در `:root`، آیکون‌ها به‌صورت
SVG `<symbol>` و منطق صفحه در پایان فایل. برای تغییر محتوا، کافی است بخش‌های HTML را ویرایش کنید؛
هر متن دوزبانه دو گرهٔ `<span class="fa">` و `<span class="en">` دارد.

## نکته‌های شخصی‌سازی

| چه چیزی | کجا |
| --- | --- |
| رنگ اصلی | `--accent` در `:root` |
| متن‌ها و پروژه‌ها | بخش‌های `#about`، `#work`، `#awards`، `#contact` |
| آیدی‌های تماس | لینک‌ها و `data-copy` در بخش `#contact` |
| عنوان شغلی متحرک | آرایهٔ `ROLES` در اسکریپت |
| اطلاعات vCard | تابع `downloadVCard` در اسکریپت |
